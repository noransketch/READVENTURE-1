# Design source

PNG asli (latar transparan) untuk gambar kata World 1 dan World 2, plus latar header-nya.
App tidak memakai folder ini; app memakai versi .webp yang lebih ringan di `assets/vocab/` dan `assets/world/`.
Folder ini disimpan supaya gambar bisa dipakai lagi (misalnya untuk laporan atau slide).
